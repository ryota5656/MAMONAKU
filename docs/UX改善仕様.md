# UX 改善仕様

## 目的

日常利用での日付移動・タスク作成・Live Activity 更新導線の摩擦を下げる。

## スコープと優先度

1. LA 未反映インジケータ（赤ドット）修正
2. タイムラインタブ再タップで今日 / 現在時刻へ戻る
3. CalendarHeader 日付の連続横スクロール（シェブロン削除）
4. 長押しで duration をスライド決定してからタイトル入力

---

## 1. LA 未反映インジケータ

### 現状

右下アクションタブにシステム `.badge(1)` を付けており、Liquid Glass でバッジがクリップされる。

### 仕様

- `.badge` は使わない
- 未反映時（およびチュートリアル完了促し時）は **オレンジの点のみ** をアイコン右上に重ねる
- 数字は出さない

---

## 2. 今日に戻る（タイムラインタブ再タップ）

| 状態 | 挙動 |
|------|------|
| 他タブ → タイムライン | タブ移動のみ（日付は維持） |
| タイムライン表示中 かつ 今日以外 | `selectedDate` を今日にし、現在時刻付近へスクロール |
| タイムライン表示中 かつ 今日 | 現在時刻付近へスクロール |

- 2日表示中に今日へ戻す場合は 2日表示を解除する
- 同じタブの再タップ検知が必要なため、TabBar の再選択を拾う

---

## 3. CalendarHeader 日付スクロール

### 仕様

- 週固定 + 左右シェブロンを廃止
- 日付を横方向に連続スクロールできるストリップにする
- 日付タップで選択
- 選択日が変わったらストリップ中央付近へ追従スクロール
- 同一日の再タップで 2日表示トグルは維持
- 月カレンダー sheet からの日付選択も従来どおり

---

## 4. 長押しで duration スライド

### フロー

```text
空き領域を長押し
  → その Y 位置の開始時刻で仮ブロック表示（初期 duration = 30分）
  → 指を上下に動かして長さだけ変更（開始時刻は固定、5分刻み）
  → 既存タスクと重なる手前でストップ
  → 指を離すとタイトル入力
  → 確定 / 外タップでキャンセル
```

### 詳細

| 項目 | 値 |
|------|-----|
| 開始時刻 | 長押し開始位置（固定） |
| 初期 duration | 30 分 |
| 刻み | 5 分 |
| 最小・最大の人工キャップ | なし（ただし 5 分未満にはしない、終日/重なりで実質上限） |
| 重なり | 次の予定の手前でストップ |

---

## 受け入れ条件

1. LA 未反映時、更新アイコン右上に点が切れずに見える。数字バッジは出ない
2. タイムラインタブ再タップで今日以外→今日＋現在時刻、今日→現在時刻スクロール
3. ヘッダー日付を横スクロールでき、シェブロンがない
4. 長押しドラッグで長さが変わり、離すとタイトル入力になる。重なり手前で止まる
