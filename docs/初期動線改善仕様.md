# 初期動線改善仕様

## 目的

初回起動からコア価値（タスク配置 → Live Activity 更新）までの到達率を上げ、継続率の土台を作る。

背景（GA）:

- `first_open` に対し `onboarding_complete` が約 12% と低い
- 説明オンボーディングと長い初回ガイドが、価値体験前の離脱要因になっている
- 起動直後の通知許可ダイアログも摩擦になっている

## 方針

1. **説明オンボーディングを廃止**し、起動直後からタイムラインを使える状態にする
2. **チュートリアルは最小限（2ステップ）**にし、コア操作そのもので学習させる
3. **通知許可は LA 更新成功後**に遅延する
4. **スキップ可能**にし、強制完了させない

## 初期動線（確定）

```text
起動
  → タイムラインを即表示
  → Stock にプリセットタスク「はじめてのタスク」を用意
  → [Step1] 現在時刻より後へドラッグ＆ドロップ
  → 編集モードへ自動遷移（右下が完了 ✓）
  → [Step2] 右下の完了を促す
  → 完了タップで LA / クラウド同期
  → チュートリアル完了
  → （任意）通知許可ダイアログ
```

ロック画面への強制誘導は行わない。完了同期によりアプリ内で LA が更新されることを aha とする。

## スコープ

### やる

| 項目 | 内容 |
|------|------|
| オンボーディング削除 | `OnboardingView` の fullScreenCover を出さない |
| セッション計測 | オンボーディング完了待ちをやめ、起動時点でセッション計上 |
| プリセットタスク | 初回チュートリアル開始時、Stock が空なら 1 件追加 |
| 最小チュートリアル | `placeTaskAfterNow` → `confirmComplete` の 2 ステップ |
| 完了で同期 | 編集完了（✓）で LA 同期（既存実装をチュートリアル完了条件に接続） |
| 通知許可遅延 | `didFinishLaunching` では許可ダイアログを出さない。チュートリアル完了（非スキップ）後にリクエスト |
| スキップ | ガイドに「あとで」。押下でチュートリアル終了（通知は出さない） |

### やらない（本スコープ外）

- ロック画面確認の必須ステップ
- カウントダウン確認ステップ
- Stock タップ / タイトル入力の作成ガイド
- オンボーディング画像アセットの削除整理（ファイル残留は可）
- 既存ユーザーの強制再チュートリアル

## チュートリアル詳細

### 表示条件

- `tutorial.firstRun.completed != true`
- Preview では非表示

### Step1: `placeTaskAfterNow`

- メッセージ: Stock のタスクをドラッグして、現在時刻より後のタイムラインへ置いてみましょう。
- Stock カードをハイライト
- 操作: プリセット（または既存 Stock）を今より後へ D&D
- 成功時: 編集モードへ入り、Step2 へ進む
- CTA: 「あとで」のみ（スキップ）

### Step2: `confirmComplete`

- メッセージ: 右下の完了（✓）をタップして、Live Activity を更新しましょう。
- 右下アクションタブにバッジを付けて完了を促す
- 操作: 完了タップ → LA 同期
- 成功時: チュートリアル完了 → 通知許可リクエスト（未決定時のみ）
- CTA: 「あとで」のみ（スキップ）

### プリセットタスク

- タイトル: `はじめてのタスク`
- 所要: 30 分
- 優先度: Low（無料プランで作成可能な値）
- 追加条件: チュートリアル開始時点で Stock（`dropDate == nil`）が 0 件のときのみ
- スキップしても削除しない

## 通知許可

| タイミング | 挙動 |
|------------|------|
| 起動時 | `registerForRemoteNotifications` のみ（許可ダイアログなし）。匿名 Auth / LA Push 観測は継続 |
| チュートリアル完了（完了✓経由） | `authorizationStatus == .notDetermined` のときだけシステムダイアログ |
| スキップ | 通知許可は出さない（設定から従来どおり取得可能） |

## 計測

| イベント | 発火条件 |
|----------|----------|
| `first_run_complete` | 初回チュートリアル完了時。`skipped: true/false` |
| `live_activity_refresh` | 完了/更新による同期時（既存） |
| `onboarding_complete` | **新規発火しない**（説明オンボーディング廃止のため） |

旧 `onboarding_complete` は新規ユーザーでは減る想定。初回到達の新指標は `first_run_complete`。

## 既存データ互換

- `onboarding.hasSeen` は参照しなくなる（残置可）
- `tutorial.firstRun.completed` が true のユーザーには新チュートリアルを出さない
- 未完了ユーザーには新 2 ステップを表示する

## 受け入れ条件

1. 新規インストールで説明オンボーディングが出ず、タイムラインがすぐ見える
2. Stock に「はじめてのタスク」がある（Stock が空の場合）
3. D&D → 編集モード → 完了で LA が更新され、チュートリアルが終わる
4. 起動直後に通知許可ダイアログが出ない
5. 「あとで」でチュートリアルを終了でき、通常利用に入れる
6. 起動直後からセッションカウントが動き、3/5 セッション目の既存プロンプト条件が維持される
